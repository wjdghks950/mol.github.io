# Mixture of Layers

Project website for **Mixture of Layers: Dynamic Layer Routing for Visual Reasoning**.

**Website:** https://wjdghks950.github.io/mol.github.io/

The static site lives in `website/`. GitHub Actions checks and publishes changes to `main` through GitHub Pages.

Preview locally:

```sh
python3 -m http.server 8765 --directory website
```

See [website documentation](website/README.md) for content provenance, paper refresh instructions, and deployment details.
